Claude Cheat Sheet

Quick reference for Chat, Cowork & Code — keep this handy!

A note from Robin: I'm not an AI expert — just a colleague who's been exploring Claude and found it genuinely useful. This cheat sheet is me sharing what I've learned. Think of it as peer-to-peer, not a vendor pitch.

The Three Interfaces

Chat

You think together.

Brainstorming, writing, analysis, Q&A. Available in browser, desktop & mobile.

Best for: quick questions, content creation, analysis of pasted data

Cowork

Claude works for you.

Files, documents, tools, multi-step tasks. Runs in the desktop app.

Best for: creating deliverables, automating workflows, connecting tools

Code

Claude builds with you.

Terminal, IDE, entire codebases, tests, PRs. For developers.

Best for: writing code, debugging, refactoring, code reviews

Claude vs Google: When to Use Which

Use Claude when...Use Google when...
You need to synthesize — combine, analyze, draw conclusionsYou need a specific fact — phone number, address, hours
You need a first draft — email, report, summary, planYou need a specific link — website, form, login page
You need to work with your data — analyze, reformat, transformYou're browsing — shopping, reviews, reading news
You need to iterate — keep refining until it's rightYou need real-time info — stock prices, flight status, scores
Think of it this way: Google is a librarian who points you to the right book. Claude is a colleague who reads the book for you and gives you a summary.

  • Pay per input + output token
  • For building your own apps on top of Claude
  • Full control over parameters like temperature

How Claude "Thinks": Probability & Temperature

Claude is probabilistic, not deterministic. It predicts the most likely next word — so the same prompt can give slightly different answers each time. This isn't a bug, it's how LLMs work.

Temperature is the "creativity dial":

SettingBehaviourGood for
Low (0)Focused, consistent, predictableData extraction, classification, structured output
High (1)Varied, creative, surprisingBrainstorming, creative writing, exploration
Key difference: In Chat, Cowork & Code CLI, temperature is not configurable (Anthropic sets it). Via the API, you can set it yourself — crucial for production use cases where you need consistent, repeatable results.

Prompt Evolution: Bad → Decent → Great

LevelPromptWhy
Bad"Make a report"No context, no format, no audience
Decent"Summarize our Q4 results"Better, but vague about format and depth
Great"Create a one-page executive summary of Q4 results with revenue by region in a table, top 3 risks highlighted, and a recommendation section. Format as a Word doc."Specific format, audience, structure, output
The formula: What do you need + for whom + in what format. You don't need essay-length prompts — just be specific.

Prompting Tips

Do This ✓

  • Be specific about format and structure
  • Mention the output you want (Word doc, spreadsheet, etc.)
  • Iterate: "now make it shorter", "add a chart"
  • Give context: "This is for the executive team"

Avoid This ✗

  • Vague one-liners without context
  • "Make it better" (better how?)
  • Multiple unrelated tasks in one prompt
  • Assuming Claude remembers previous sessions
Pro tip: Set up a CLAUDE.md file with your role, preferences, and recurring instructions. It applies to every session automatically — like setting your IDE preferences once.

Privacy Myth-Busting

MythReality
"Claude remembers everything I said last time"Each session starts fresh. No memory of previous conversations.
"Claude is reading all my files"Only the files in the folder you select. Nothing else on your computer.
"Cowork runs in the cloud"Cowork runs in a sandbox on YOUR computer. But prompts/responses go through Anthropic's servers.
"AI will replace my job"Claude is a tool that makes you faster — like email and spreadsheets before it.
